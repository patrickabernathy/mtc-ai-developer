## What this program is

You'll learn to build modern web applications end to end — front-end and back-end — using
HTML, CSS, JavaScript, TypeScript, React, APIs, databases, and scalable systems. Alongside
that, you'll get hands-on experience using AI tools to write, debug, and optimize code, and
learn Agile and Scrum practices for working effectively on a software team.

The emphasis is on building. You'll write real code, break real things, fix them, and ship a
portfolio-ready project.

**No prior technical background is assumed.** We start from the beginning.

## The three courses

The certificate is made up of three courses, delivered **virtually** with a live instructor
and classmates:

| Course | Hours | CEUs | Course ID |
|---|---|---|---|
| **AI Enabled Front-End Development** | 96 | 9.60 | CEWDV-593 |
| **AI Enabled Back-End Developer** | 48 | 4.80 | CEWDV-594 |
| **Agile Fundamentals** | 18 | 1.80 | CEPMG-573 |

### AI Enabled Front-End Development

Build a foundation in modern front-end development while learning to use AI as a practical
coding partner. Develop responsive, interactive user interfaces with HTML, CSS, JavaScript,
and TypeScript, and work with components and state in React. Translate designs into
functional user experiences while applying best practices in usability, performance, and
accessibility. You'll use AI tools for coding, debugging, and optimization — building both
technical skill and the judgment to know when to trust the output.

### AI Enabled Back-End Developer

Design and develop scalable back-end systems while using AI to enhance your workflow. Create
APIs, manage data with industry-standard structures, and apply core algorithms for efficient
performance. Explore the HTTP request/response cycle, RESTful API design, and technologies
like GraphQL and WebSockets. Implement essential security practices including
authentication, data protection, and secure communication — and get comfortable working in
the command line.

### Agile Fundamentals

The Agile values and principles behind modern software delivery, focused on *being* Agile
before *doing* Agile. Covers Scrum — the most widely used Agile methodology — including team
roles, responsibilities, and how to contribute effectively on a development team. This
course prepares you for the Professional Scrum Master I (PSM I) certification and introduces
PMI's Agile Certified Practitioner (PMI-ACP)®.

## A note on how this class runs

Most of our time is spent on live demos and hands-on work, not lecture. Things will break on
screen on purpose — watching a bug get diagnosed and fixed teaches more than a working
example ever does. Expect to be asked what you think will happen *before* we hit run.

Bring questions. Getting stuck is the job, not a sign you're behind.
